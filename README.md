## Archivos

- `hola_mundo.cpp`: imprime un saludo.
- `tarjeta_de_presentacion.cpp`: muestra una tarjeta con nombre y edad.
- `imc.cpp`: calcula el IMC a partir de peso y altura.
- `tablademultiplicar.cpp`: genera una tabla de multiplicar hasta el limite indicado.
- `proyecto.cc`: permite consultar varias tablas de multiplicar en una sola ejecucion.
- `calificaciones.cpp`: calcula el promedio de varias calificaciones e indica si se aprueba o reprueba.
- `calculadora.cpp`: suma, resta, multiplica o divide dos numeros segun la opcion elegida.
- `conversor.cpp`: convierte unidades (kilometros a metros, metros a centimetros y celsius a fahrenheit).
- `mayor3.cpp`: ordena tres numeros e indica cual es el mayor, el mediano y el menor.
- `cajero.cpp`: simula un cajero automatico para depositar, retirar y ver el saldo.
- `adivina.cpp`: juego para adivinar un numero aleatorio del 1 al 100.
- `contador_vocales.cpp`: cuenta las vocales y consonantes de un texto.
- `palindromo.cpp`: verifica si una palabra o texto es palindromo.

## Compilar

```bash
clang++ archivo.cpp -o programa
```
